# seek.li Mailbox Worker

基于 Cloudflare Worker 的 HTTP 网关，对接 **seek.li** 仅有的两个 Mailbox OpenAPI 接口，并为 **Bitwarden 邮箱别名生成器** 提供兼容层。

> **给他人使用？** 请看 [SETUP.md](./SETUP.md)，从 Fork 到 Bitwarden 配置，一步步说明。

> **重要**：seek.li 不是完整的 SimpleLogin 实例，仅支持 Mailbox 检查与创建，**不能**直接填入 Bitwarden 的「自托管服务器 URL」。必须通过本 Worker 做协议转换。

## 架构说明

```
Bitwarden 生成器                    脚本 / HTTP 客户端
      │                                    │
      │ POST /api/alias/random/new         │ POST /mailboxes/check
      │                                    │ POST /mailboxes
      ▼                                    ▼
              Cloudflare Worker（本项目）
                         │
          ┌──────────────┴──────────────┐
          │  Bitwarden 兼容层：          │
          │  生成随机地址 → check → create │
          └──────────────┬──────────────┘
                         │
                         ▼
              seek.li（仅 2 个接口）
              POST /openapi/v1/mailboxes/check
              POST /openapi/v1/mailboxes
```

## 功能

| 方法 | 路径 | 用途 |
|------|------|------|
| `GET` | `/` 或 `/health` | 健康检查 |
| `POST` | `/api/alias/random/new` | **Bitwarden 专用**：模拟 SimpleLogin 随机别名创建 |
| `POST` | `/mailboxes/check?address=<邮箱>` | 直接代理 seek.li 检查接口 |
| `POST` | `/mailboxes` | 直接代理 seek.li 创建接口 |

## Bitwarden 配置（重点）

部署 Worker 后，在 Bitwarden 生成器中这样填写：

| Bitwarden 字段 | 填写内容 |
|----------------|----------|
| **服务** | SimpleLogin |
| **电子邮箱域名** | 与 Worker 的 `DEFAULT_EMAIL_DOMAIN` 一致，例如 `example.com` |
| **API 密钥** | Worker 的 `WORKER_API_TOKEN`（在 Cloudflare 控制台设置） |
| **自托管服务器 URL** | **Worker 地址**，例如 `https://simplelogin-mailbox-worker.xxx.workers.dev` |

> 不要填 `https://seek.li`，Bitwarden 会调用 `/api/alias/random/new`，而 seek.li 不支持该接口。

### 工作原理

Bitwarden 调用 `POST /api/alias/random/new` 时，Worker 会：

1. 根据 `DEFAULT_EMAIL_DOMAIN` 生成随机邮箱地址（如 `a3f8b2c1@example.com`）
2. 调用 seek.li 的 `/mailboxes/check` 检查可用性
3. 调用 seek.li 的 `/mailboxes` 创建邮箱
4. 返回 Bitwarden 期望的格式：`{ "alias": "a3f8b2c1@example.com" }`

- [Node.js](https://nodejs.org/) 18+

## 快速开始

### 1. 安装依赖

```bash
cd simplelogin-mailbox-worker
npm install
```

### 2. 配置本地环境变量

```bash
cp .dev.vars.example .dev.vars
```

编辑 `.dev.vars`：

```env
SIMPLELOGIN_API_TOKEN=你的_seekli_Token
DEFAULT_EMAIL_DOMAIN=你的域名.com
WORKER_API_TOKEN=自定义的_Worker_访问令牌
```

### 3. 本地开发

```bash
npm run dev
```

### 4. 部署

```bash
npx wrangler login
npx wrangler secret put SIMPLELOGIN_API_TOKEN
npx wrangler secret put WORKER_API_TOKEN
npm run deploy
```

## GitHub 仓库绑定部署

### 推送代码

```bash
git init
git add .
git commit -m "init: seek.li mailbox worker"
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

### Cloudflare 控制台绑定

1. **Workers & Pages** → **Create** → **Connect to Git**
2. 选择仓库，构建设置：
   - Build command: `npm install`
   - Deploy command: `npx wrangler deploy`
3. **Settings → Variables and Secrets** 填写：

| 变量名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `SIMPLELOGIN_API_TOKEN` | Secret | 是 | seek.li API Token |
| `WORKER_API_TOKEN` | Secret | 是 | Bitwarden「API 密钥」填此值 |
| `DEFAULT_EMAIL_DOMAIN` | Text | 是 | 创建邮箱使用的域名 |
| `SIMPLELOGIN_BASE_URL` | Text | 否 | 默认 `https://seek.li` |

> `wrangler.jsonc` 已设置 `"keep_vars": true`，Git 部署不会覆盖控制台变量。

## API 使用说明

### 认证方式

| 调用方 | 认证 Header |
|--------|-------------|
| Bitwarden | `Authentication: <WORKER_API_TOKEN>` |
| 脚本 / curl | `Authorization: Bearer <WORKER_API_TOKEN>` |

Worker 调用 seek.li 时自动附加 `Authorization: Bearer <SIMPLELOGIN_API_TOKEN>`。

### 直接调用 Mailbox 接口

```bash
# 检查可用性
curl -X POST 'https://<worker>/mailboxes/check?address=test@example.com' \
  -H 'Authorization: Bearer <WORKER_API_TOKEN>'

# 创建邮箱
curl -X POST 'https://<worker>/mailboxes' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <WORKER_API_TOKEN>' \
  -d '{"address": "custom@example.com"}'
```

### Bitwarden 兼容接口

```bash
curl -X POST 'https://<worker>/api/alias/random/new?hostname=example.com' \
  -H 'Authentication: <WORKER_API_TOKEN>' \
  -H 'Content-Type: application/json' \
  -d '{"note": "Generated by Bitwarden."}'
```

响应：

```json
{
  "alias": "example.a3f8b2c1@yourdomain.com"
}
```

## 环境变量

| 变量 | 类型 | 说明 |
|------|------|------|
| `SIMPLELOGIN_BASE_URL` | Text | seek.li 地址，默认 `https://seek.li` |
| `SIMPLELOGIN_API_TOKEN` | Secret | seek.li API Token，Worker 调用上游用 |
| `DEFAULT_EMAIL_DOMAIN` | Text | 创建邮箱的域名，与 Bitwarden「电子邮箱域名」一致 |
| `WORKER_API_TOKEN` | Secret | 保护 Worker，Bitwarden「API 密钥」填此值 |
